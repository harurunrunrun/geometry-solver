# 二次元幾何Solver

Generated by Chat GPT 5.6 xhigh

## 1. 使用例

```cpp
#include "solver.hpp"
#include <iostream>

int main() {
    gs::GeoSolver<> solver;
    auto A = solver.point();
    auto B = solver.point();
    auto C = solver.point();

    solver.add_distance2(A, B, 25);
    solver.add_distance2(A, C, 144);
    solver.add_perpendicular(A, B, A, C);

    auto result = solver.query_value(solver.dist2_expr(B, C));
    std::cout << result.value << '\n'; // 169
}
```


## 2. 記法と規約

- 距離と半径は、特記がない限り二乗値で渡す。`d2`、`r2`、`radius_squared` はそれぞれ距離の二乗、半径の二乗を表す。
- `AB` は点 `A` から点 `B` への有向ベクトルを表す。
- `*_ccw` は頂点が反時計回りに並んでいることを前提とする。
- `add_*` は制約を追加する。複数の条件へ展開されるAPIは `std::array<ConstraintId, N>` または `void` を返す。
- `construct_*` は出力点に必要な制約を追加し、構成ノードも登録する。
- 数値が `value` に入っていても、それだけでは認証済みとは限らない。必ず `status` と認証フラグを確認する。
- `Rational` 版と `long long` 版があるAPIでは、整数は `Rational` へ変換して処理される。

### 3.4 `SolveStatus`

| 値 | 意味 |
|---|---|
| `ExactRational` | 厳密有理数として求まった。 |
| `DerivedValue` | 制約の厳密な関係から値が一意に導かれた。 |
| `CertifiedAlgebraic` | Sturm列などで分離区間を持つ代数的数として認証した。 |
| `VerifiedNumeric` | 数値解を元の制約へ戻して検証した。 |
| `MultipleSolutionsSameValue` | 配置は複数あるが、問い合わせ値は共通。 |
| `MultipleValues` | 問い合わせ値が複数ある。 |
| `Underdetermined` | 連続自由度または未固定のスケールが残る。 |
| `FrameDependent` | 座標系を固定していない問題で絶対座標を問い合わせた。 |
| `Infeasible` | 条件を同時に満たす配置がない。 |
| `BranchLimit` | 分岐候補数が設定上限を超えた。 |
| `NumericallyUncertain` | 現在の数値処理では安全に結論できない。 |
| `OverflowRisk` | 固定幅整数構成で安全な範囲を超えた。 |
| `Unsupported` | 現在の求解器が扱わない形。 |
| `Unbounded` | 目的関数が下または上に非有界。 |
| `OptimumNotAttained` | 有限の下限・上限はあるが、実行可能点では達成されない。 |

### 3.5 式に関する型

| 型 | 用途 |
|---|---|
| `AffineExpr<N>` | `N` 変数のアフィン式。 |
| `QuadPoly<N>` | `N` 変数の二次以下の多項式。 |
| `UniPoly` | 一変数多項式。 |
| `RootInterval` | 実根の分離区間、近似値、重複度を保持する。 |
| `QueryTrait` | 問い合わせ式の平行移動・回転・鏡映・拡大縮小に対する性質を指定する。 |
| `ValueExpr` | `GeoSolver` に渡す値問い合わせ式。通常は `*_expr` で作る。 |

`QueryTrait` の各フィールドは次の意味を持つ。

```cpp
struct QueryTrait {
    bool translation_invariant;
    bool rotation_invariant;
    bool reflection_invariant;
    int8_t scale_degree;
    bool requires_absolute_frame;
};
```

`raw_value_expr` を使う場合、これらを式の性質に合わせて正しく設定する。誤った指定は、座標なし問題の正規化や不定性判定を誤らせる。

## 4. `GeoSolver` の宣言

```cpp
template<
    int MAX_P = GS_MAX_POINTS,
    int MAX_C = GS_MAX_CONSTRAINTS,
    int MAX_V = GS_MAX_VARIABLES,
    int MAX_K = GS_MAX_CONSTRUCTIONS
>
class GeoSolver;
```

| テンプレート引数 | 内容 |
|---|---|
| `MAX_P` | 点の最大数。 |
| `MAX_C` | 制約の最大数。 |
| `MAX_V` | 座標変数の最大数。`2 * MAX_P` 以上が必要。 |
| `MAX_K` | 構成ノードの最大数。 |

公開される低水準型は次の二つ。

```cpp
using RawAffine = AffineExpr<2 * MAX_P>;
using RawPolynomial = QuadPoly<2 * MAX_P>;
```

## 11. 低水準の式API

通常の幾何条件で足りる場合、この節のAPIを使う必要はない。独自の二次制約や目的式を組み立てる場合に使う。

| API | 内容 |
|---|---|
| `RawAffine raw_x(PointId p) const;` | 点 `P` のx座標をアフィン式として返す。 |
| `RawAffine raw_y(PointId p) const;` | 点 `P` のy座標をアフィン式として返す。 |
| `static RawPolynomial raw_linear(const RawAffine& expression);` | アフィン式を二次多項式型へ変換する。 |
| `static RawPolynomial raw_product(const RawAffine& a, const RawAffine& b);` | 二つのアフィン式の積を返す。 |
| `RawPolynomial raw_dist2(PointId a, PointId b) const;` | `\|AB\|^2` の多項式を返す。 |
| `RawPolynomial raw_dot(PointId a, PointId b, PointId c, PointId d) const;` | `AB・CD` の多項式を返す。 |
| `RawPolynomial raw_cross(PointId a, PointId b, PointId c, PointId d) const;` | `cross(AB, CD)` の多項式を返す。 |
| `RawPolynomial raw_polygon_area2(const std::vector<PointId>& polygon) const;` | 多角形の符号付き二倍面積を返す。反時計回りが正。 |
| `RawPolynomial raw_circle_power(PointId p, PointId center, const Rational& radius_squared) const;` | `\|P-center\|^2 - radius_squared` を返す。 |
| `ConstraintId add_polynomial_equal_zero(const RawPolynomial& polynomial);` | `polynomial == 0` を追加する。 |
| `ConstraintId add_polynomial_greater_equal_zero(const RawPolynomial& polynomial);` | `polynomial >= 0` を追加する。 |
| `ConstraintId add_polynomial_greater_zero(const RawPolynomial& polynomial);` | `polynomial > 0` を追加する。 |
| `ValueExpr raw_value_expr(const RawPolynomial& polynomial, QueryTrait trait = QueryTrait{false,false,false,0,true});` | 任意の二次多項式を問い合わせ式として保存する。`trait` は利用側で正しく指定する。 |

`RawAffine` と `RawPolynomial` は通常の演算子 `+`、`-`、スカラー倍などで組み合わせられる。

#### 偏角順と方向区間


`normalize_direction` は零でない整数ベクトルを最大公約数で割り、向きを保った原始ベクトルへ直す。反対向きのベクトルは同一視しない。零ベクトルを渡した場合は零ベクトルを返す。

```cpp

    void reset(const std::vector<PointI>& directions);
    void reset(const std::vector<std::pair<PointI, long long>>& weighted_directions);

    long long total_weight() const;
    size_t distinct_direction_count() const;
```

## 結果の状態

- `ExactRational`：厳密有理数
- `CertifiedAlgebraic`：Sturm区間で認証された代数的数の近似
- `VerifiedNumeric`：元制約への再代入に成功した数値解
- `MultipleValues`：問い合わせ値が複数
- `Underdetermined`：連続自由度が残る
- `Infeasible`：解なしを認証
- `OverflowRisk`：固定幅整数構成で安全範囲を超えた
- `Unbounded`：目的関数が非有界
- `OptimumNotAttained`：上限または下限はあるが達成されない
- `NumericallyUncertain` / `Unsupported`：現在の方法では安全に結論できない

## 設定マクロ

### `GS_USE_CPP_INT`

| 既定値 | 設定値 | 内容 |
|---:|---:|---|
| `1` | `1` | `boost::multiprecision::cpp_int` を使う。整数演算は任意精度。 |
|  | `0` | 検査付き `__int128` を使う。範囲を超える演算は `IntegerOverflow` として検出され、問い合わせ結果では原則として `SolveStatus::OverflowRisk` になる。 |

既知の整数座標に対する通常の幾何判定を中心に使い、コンパイル時間を短くする場合は `0` にする。

### `GS_MAX_POINTS`

- 既定値：`16`
- `GeoSolver<>` が保持できる点の最大数。
- 点1個につきx座標とy座標の2変数を使う。

### `GS_MAX_CONSTRAINTS`

- 既定値：`64`
- 高水準制約の最大数。
- 実際の使用数には余裕を持たせる必要あり。

### `GS_MAX_VARIABLES`

- 既定値：`2 * GS_MAX_POINTS`
- 座標変数の最大数。
- 通常は変更しない。`2 * GS_MAX_POINTS` 未満にすると、すべての点へ変数を割り当てられない。

### `GS_MAX_CONSTRUCTIONS`

- 既定値：`GS_MAX_CONSTRAINTS`
- 構成グラフへ登録できる構成ノードの最大数。

### `GS_MAX_RAW_POLYNOMIALS`

- 既定値：`2 * GS_MAX_CONSTRAINTS`
- `add_polynomial_*` で登録する低水準多項式制約の最大数。

容量を増やすと `GeoSolver` オブジェクト、固定長配列、二次式の係数表が大きくなる。特に `GS_MAX_POINTS` と `GS_MAX_VARIABLES` は二次式の保存量へ二次的に影響する。必要な範囲だけ増やす。

### `GS_MAX_ROOT_INTERVALS`

- 既定値：`64`
- 一変数多項式から保持する実根分離区間の最大数。
- 上限を超えた場合、全解列挙を完了できず `BranchLimit` または非認証結果になることがある。

### `GS_ROOT_REFINE_STEPS`

- 既定値：`12`
- 通常の実根分離区間を追加で細分する回数。
- 大きくすると近似誤差は小さくなるが、有理数の分子・分母と実行時間が増える。

### `GS_OPTIMIZATION_ROOT_REFINE_STEPS`

| 構成 | 既定値 |
|---|---:|
| `GS_USE_CPP_INT=1` | `80` |
| `GS_USE_CPP_INT=0` | `28` |

最適化候補となる一変数根の細分回数。固定幅整数版では分母肥大化を避けるため小さくしている。

### `GS_OPTIMIZATION_BOUNDARY_REFINE_STEPS`

| 構成 | 既定値 |
|---|---:|
| `GS_USE_CPP_INT=1` | `48` |
| `GS_USE_CPP_INT=0` | `24` |

一変数領域の境界値を評価するときの細分回数。

### `GS_ENABLE_QUADRATIC_CANCELLATION`

- 既定値：`1`
- 複数の二次等式を線形結合し、二次項を消去する前処理を有効にする。
- 二円から根軸を導出する処理、共通Hessianを持つ二次曲線の線形化などに使う。

`0` にするとコード経路と前処理時間を減らせるが、本来一変数へ落とせる問題が数値バックエンドへ回ることがある。

### `GS_QUADRATIC_SEMIDEFINITE_COMBINATION_MAX`

- 既定値：`512`
- 二次等式の線形結合から半正定値・半負定値な式を探す候補数の上限。
- 上限を増やすと特異二次系を線形化できる可能性が上がるが、前処理時間も増える。

### `GS_BOUND_PROPAGATION_ITERATIONS`

- 既定値：`32`
- 線形不等式、座標範囲、分離二次式から変数の上下界を伝播する最大反復回数。
- 区間分枝限定へ渡す初期箱の縮小に使う。

### `GS_ENABLE_INTERVAL_CERTIFICATION`

- 既定値：`1`
- 区間演算、Krawczyk作用素、候補解の一意性認証を有効にする。
- `0` にすると数値候補は生成できても、`feasibility_certified` や `solution_set_complete` を立てられる範囲が狭くなる。

KKTおよびFritz–Johnバックエンドは、このマクロとLevenberg–Marquardt法の両方が有効な場合だけ動作する。

### `GS_ENABLE_INTERVAL_BRANCH`

- 既定値：`1`
- 有界箱の分枝限定、孤立解列挙、区間大域最適化を有効にする。

無効化しても、線形計画、低次数代数求解、円・楕円専用最適化などは利用できる。

- 既定値：`1`
- 有理数二段階シンプレックスを有効にする。
- 線形等式・不等式だけの問題では、非有界性、狭義不等式の充足可能性、未達最適値を厳密に判定できる。

| 関連マクロ | 既定値 | 内容 |
|---|---:|---|
| `GS_EXACT_LP_MAX_ROWS` | `160` | シンプレックス表の制約行数上限。 |
| `GS_EXACT_LP_MAX_COLUMNS` | `192` | 変数、スラック変数、人工変数を含む列数上限。 |

上限を超えた問題は線形専用経路を使わず、他のバックエンドへ回るか `Unsupported` になる。

### `GS_ENABLE_EXACT_CONVEX_QP`

- 既定値：`1`
- 正定値二次目的関数と線形制約からなる凸二次計画の厳密活性集合解法を有効にする。

| 関連マクロ | 既定値 | 内容 |
|---|---:|---|
| `GS_EXACT_QP_MAX_INEQUALITIES` | `14` | 列挙対象とする線形不等式数の上限。 |
| `GS_EXACT_QP_MAX_ACTIVE_SETS` | `20000` | 検査する活性集合数の上限。 |

不等式数を増やすと活性集合数が指数的に増えるため、上限の変更は慎重に行う。

### `GS_ENABLE_ELLIPSOID_QUADRATIC_OPTIMIZATION`

- 既定値：`1`
- 中心化できる円・楕円上、またはその内外での二次目的関数を一般化固有値問題へ還元する専用処理を有効にする。

### `GS_ELLIPSOID_QUADRATIC_MAX_VARIABLES`

- 既定値：`7`
- 上記専用処理の変数数上限。

### `GS_ENABLE_GENERAL_ELLIPSOID_QUADRATIC_OPTIMIZATION`

- 既定値：`1`
- 目的関数の中心と楕円中心が一致しない一般形を、KKT乗数の消去多項式へ還元する処理を有効にする。

### 一般形の調整項目

| マクロ | 既定値 | 内容 |
|---|---:|---|
| `GS_GENERAL_ELLIPSOID_MAX_VARIABLES` | `5` | 一般形専用処理の変数数上限。 |
| `GS_GENERAL_ELLIPSOID_ROOT_REFINE_STEPS` | `72` (`cpp_int`) / `4` (`__int128`) | KKT乗数根の細分回数。 |

固定幅整数版の既定値が小さいのは、消去多項式の分母肥大化を避けるためである。
